zp-branding
===========

A Zenphoto plugin to replace the default Zenphoto logo on the backend with a custom logo and the possibility to use custom CSS to change the appearance of the logo and/or backend.

Version 2.0 is a combination of the 1.4 version and kuzzzma's admin-branding plugin (https://github.com/kuz-z-zma/adminBranding)


**Options:**

 - Select *No logo*, *Default logo* or *Custom logo*.
 - Set width, height is proportional.
 - Add custom inline CSS to change the appearance of the logo and/or backend.
 - Select the custom logo you want to use from the */uploaded/adminlogo/* folder.
 - Supports translations.


**Installation:**
 
 1. Copy "/zp-branding" folder and "zp-branding.php" into the */plugins/* folder of your Zenphoto installation.
2. Enable the "zp-branding" plugin on the backend.
3. Upload custom logo images into */uploaded/adminlogo/* folder (see above).
4. Set plugin options as you wish.
